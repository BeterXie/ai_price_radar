# 机器人快照搜索

报价查询使用「发布时分类 → 本地快照缓存 → 条件搜索 → 模板回复」。默认使用规则理解查询；可以在后台按 [QQ AI 价格助手](QQ_AI_PRICE_ASSISTANT.md) 配置模型理解自然语言、比较商品和解释交付方式。报价检索使用本地快照；AI 请求前短暂读取后台配置并关闭该数据库会话。账号绑定、个人设置、关注清单与历史降价指令仍使用原有业务接口。

## 发布内容

`pipeline/export_snapshot.py` 为每个可见商品输出全部符合公开条件的 `offers`，保留网页仍在使用的 `top_5_offers`。隐藏、未审核、不活跃、超时和已关闭店铺的报价不会进入快照。没有报价的可见商品也保留分类信息。

新快照使用 `search_schema_version: 1`，包括：

| 层级 | 字段与用途 |
| --- | --- |
| 快照 | `stale_offer_hours`：发布时采用的报价有效期，读取时继续剔除过期报价 |
| 商品 | `search_aliases`、`brand_aliases`：商品与品牌别名；`search_keywords`：补充全文搜索词 |
| 报价 | 交付形态、服务周期、质保、共享/独享、库存、币种、可信价格标记 |
| 报价 | 标签、使用场景、风险标记、分类置信度、原始标题、店铺、来源链接、观测时间及同款指纹 |
| 报价 | `click_count`：快照导出时的累计站内点击数，只用于点击热度，不表示销量 |

分类复用现有采集和发布流程。独享必须有明确文字依据，不能由“成品号”推断。缺少依据的共享/独享属性保留为 `unknown`。宽泛关键词（例如 OpenAI、subscription）用于搜索，不用于强制指定某个套餐。

## 支持的对话

```text
Claude Pro 月付，110元以内
只看独享
有质保
下一页
第二家
不限周期
清除筛选
重新搜索
我想看 Claude 平均价格
Claude 最高价
本站热门商品
分析一下 Claude Pro 月付
```

- 可以组合品牌、套餐、标题/店铺关键词、交付形态、周期、质保、库存和预算；空格分隔的补充关键词需要同时匹配。
- `80到110元`、`100元以内`、`低于100元` 等是价格条件；美元需要明确说明，例如 `20美元以内`。未指定币种的预算按人民币处理。
- 默认展示通过价格校验的可比人民币现货。`全部报价`、`共享`、`中转`、缺货或美元筛选可查看相应公开报价，并标明不属于默认可比最低价范围。没有可比报价的商品分类会展示相关报价。
- 筛选后再合并同款；不同币种分别展示，不换汇比较。每页 5 组，序号指当前页。
- 明确提到新商品或品牌时开始新搜索；单独的筛选条件接着上一次查询。`只看美区` 这类带筛选前缀的关键词会保留之前的商品和条件。
- `清除筛选` 保留当前商品或品牌；`重新搜索` 清空会话。不支持的排除条件会提示改写，不改动已有筛选。
- 默认规则检索支持上述条件组合。启用 AI 后支持自然语言查询规划、两到三项比较和交付解释；两种模式的报价都由同一公开快照生成，不提供日常聊天。
- AI 也可选择全站目录、热度排行、价格统计、库存、店铺分布和更新时间等分析工具。常见均价/最高价/热门问法有本地回退；详见 [快照分析的口径](QQ_AI_PRICE_ASSISTANT.md#快照分析的口径)。
- 价格统计保留不同店铺的报价，按同店同款去重；不同套餐、币种、交付、期限和共享属性分组。库存/目录/热度可覆盖所有公开报价，不将其全部当作可信价格样本。
- 新导出的快照包含点击数；已有不可变快照不重写。没有完整点击证据时不提供热门榜。成交价格和销量需要真实交易数据，目前不可从快照提供。

## 缓存和会话

API 从 `PUBLIC_DATA_DIR/latest.json` 找到 `v1/snapshots/{id}.json`，校验完整性后一次性替换内存索引。后续查询使用缓存；指针变化后加载新快照。缺失、损坏、旧版或过期的快照会返回明确提示。

QQ 会话按机器人 AppID、私聊/群 ID、发送人隔离；网页测试入口使用独立会话空间。匿名调用不保留上下文。进程内最多保留 1,000 个搜索会话，30 分钟无活动后过期，重启会清空。多进程部署若需要稳定连续筛选，应将同一会话路由到同一进程；当前没有共享会话存储。

快照切换后，「下一页」或「第二家」等操作先刷新列表，要求用户按新列表选择，避免旧序号指向其他报价。列表中的店铺、报价和详情始终来自同一快照版本。

## 启用条件与验证

部署新版发布器和 API 后，需要正常发布一个**新的快照 ID**，并确保 API 的 `PUBLIC_DATA_DIR` 指向发布器写入的共享目录。已有快照 URL 是不可变文件，不能覆盖同一个 ID 来补字段；旧版快照会提示等待同步。生产部署仍遵循 `docs/QUICK_DEPLOY.md`。

本地 PowerShell 验证：

```powershell
# 工作目录：apps\api
python -m pytest tests\test_snapshot_chat.py tests\test_auth_and_bot.py tests\test_qq_gateway_privacy.py tests\test_public_feed.py tests\test_user_subscriptions.py -q
if ($LASTEXITCODE -ne 0) { throw 'Bot checks failed.' }

# 工作目录：pipeline
python -m pytest tests\test_export_snapshot.py tests\test_public_offer_freshness.py tests\test_snapshot_publish.py -q
if ($LASTEXITCODE -ne 0) { throw 'Snapshot checks failed.' }
```

测试覆盖真实导出文件读取、前五条之外的条件匹配、连续筛选和分页、会话隔离/过期、快照切换、异常文件、币种和保守分类。测试不会向 QQ 或 Telegram 发送消息。
