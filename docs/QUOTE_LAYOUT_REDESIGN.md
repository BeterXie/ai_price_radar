# 报价页面改版 · 2026-11-11

用户最新范围：“不要做过于复杂的流程……清晰的展示商品报价……最快速度知道账号、代充、品牌等商品的价格、库存、最近的热度以及商品的分类……主题一致风格不一致”。

本次直接修改现有网站的报价页面，作为可运行、可编辑的样板。四站首屏均进入报价；品牌、交付类型、价格、库存、来源可直接阅读。详细原文和其他同款店铺是补充信息，不是查价的前置步骤。

- AIPrice：横向对齐的密集行情表，适合连续扫价格和库存。
- AISI：按品牌分段的暖白目录，商品与店铺并列，价格贴近标题。
- PriceIn：商品货架，品牌色签、明显价格、库存和来源按钮。
- OpenPrice：蓝白紧凑目录，左侧商品描述、右侧独立价格条。

来源：已有实际浏览记录中的水獭、AIradar、PriceAI、CardNav。借鉴直接报价与条件筛选；不采用分步向导、盲选、拖拽、坐标选点或搜索语法。现有图片生成结果作为品牌图标使用，不生成商品实物或虚构证据。

数据约束：价格和库存来自同一条代表报价；同款店铺汇总不得冒充该店铺的库存。近期热度为后台点击记录按商品汇总的最近 7 天原站访问次数，非销量、非某一家店铺的访问数；接口失败显示暂不可用。缺失库存数显示未知。

验证范围：默认/筛选/空结果、补充详情、移动端、真实价格与链接一致、主站既有路径。报价来源页与独立文章页沿用当前已部署能力。

设计状态：最新范围已明确；本次报价样板待用户检查，未批准为生产最终视觉。HTML 母版即现有 React 页面；不会增加 Figma 交付或与业务无关的流程。未执行生产发布。
