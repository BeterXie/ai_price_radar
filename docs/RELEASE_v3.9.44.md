# v3.9.44 — 恢复品牌搜索并改善匹配

所有品牌目录和商品详情页恢复搜索入口，位于筛选与仅看有货之间；手机上搜索独占一行。搜索、清空和浏览器返回保留当前品牌、商品、来源与报价筛选，提交后重置分页。

支持全角字符、粘贴空格和不可见字符规范化，增加常用品牌别名与紧凑套餐名匹配，如 Max5x、chatgptplus、谷歌 AI。多个关键词仍取交集，SQL 通配符保持字面匹配。没有搜索结果时保留原报价范围，并提供搜索全部品牌入口。

从 v3.9.43 升级无需数据库迁移或完整爬虫刷新。按 QUICK_DEPLOY.md 保留回滚材料，重建 API、Web 与 importer，验收搜索、筛选、版本和页面后恢复定时器。
