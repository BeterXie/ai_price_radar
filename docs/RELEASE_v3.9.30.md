# v3.9.30

包含 v3.9.29 的糖果测试与重复输入缓存基准，并修复异步账单的归因边界：预热和第二次请求输入完全相同，若预热账单延迟写入，其一次请求增量也可能看起来属于第二次请求。

现在先用请求次数与输入用量确认预热已经入账，才允许通过第二次请求前后的账单差额补充缓存读数。无法确认时保留未知；响应直接返回的缓存字段仍可使用。预热和第二次请求各自都有有界的用量读取，不重试模型答题，也不把等待账单的耗时计入模型延迟。

从 v3.9.28 升级仍需按 `docs/QUICK_DEPLOY.md` 执行 v25 迁移和完整多来源发布；迁移已经执行过时幂等安全。详见 `docs/RELEASE_v3.9.29.md` 中的指标口径与预算。
