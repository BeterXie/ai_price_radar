## 本次调整

- 为现有 8 个品牌建立 `/brands/{slug}` 固定入口；有报价且无筛选参数的页面允许收录，筛选和搜索变体继续 noindex 并指向品牌 canonical。
- 旧 `/products?brand=…` 与 `platform=…` 品牌入口永久跳转到新页面，保留搜索、库存、期限、来源等参数。
- 首页、菜单和报价目录使用品牌规范链接；有报价品牌和 `/compare` 加入 sitemap，数据更新时间沿用实际快照。
- 首页、品牌页和商品页标题明确比价主题，全站标题后缀缩短为 PriceMemo；报价页显示真实 H1 与已有产品说明。
- 新增 `/compare`：使用现有 API 数据展示 ChatGPT、Claude、Gemini 1 个月直充 / 代充报价、库存、来源数和更新时间，详情链接保留同一统计口径；链接官方说明与已有模型评测。
- 不把第三方商品观测价当作官方月费，不编造模型能力榜单或评测分数。

Google 的站长资源验证仍需有权限的账号完成。新 URL 被通知、可以抓取或出现在 sitemap，都不等于已被收录，更不等于排名已经提升。后续应在相同地区与语言条件下比较，并优先使用站长平台的展示量、点击率、查询词和平均位置。
