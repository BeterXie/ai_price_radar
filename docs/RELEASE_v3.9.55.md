# v3.9.55

QQ 机器人新增可选 AI 价格助手，支持自然语言查价、连续筛选、两到三项商品比较，以及成品、半成品和代充解释。价格、库存、商品条款和链接均来自已发布快照，模型仅规划只读查询；模型不可用时回退规则搜索。

后台「运营与配置 → QQ 机器人 → AI 价格助手」可配置接口地址、API 密钥、模型和接口格式，测试连接、保存启用或关闭 AI。配置保存后下一次查询读取新值，无需重启。密钥加密保存、不回显；换模型可留空保留，换接口必须提供对应密钥。初始关闭，由管理员自行配置后启用。

QQ 消息回复使用有界队列，避免模型请求阻塞网关心跳。保留现有绑定、关注和通知指令，账号筛选同时覆盖成品与半成品。
