# v3.9.24 中转站模型、分组倍率与图标稳定性

本版针对 Tosky.io、MX-API 超时排查，增加使用现有检测密钥同步模型和分组资料、每站分组选择与倍率展示，并修复站点图标间歇性缺失。申请仍由前台提交并沿用后台审核流程。

## 真实站点核验

- Tosky.io TCP/TLS 约 0.2 秒完成，响应头约 16 秒后返回，旧的 15 秒等待上限会误截断。仅模型探测调整为单次 30 秒、总计 45 秒；保留历史失败与可用率。
- MX-API 两轮完整回复约 3.3–3.6 秒。历史样本未记录失败阶段，不能断言历史超时原因。
- 四站的 `/v1/sub2api/billing` 均可通过现有密钥读取。LLMPort、Tosky、MX-API 返回当前密钥分组倍率 0.12×、0.18×、0.15×，未给出组名；AllTokens 返回企业级 0.25×、PRO 0.16×、官 Key 0.30×。该次返回未包含模型与分组映射，界面明确标注范围未知。
- Tosky 和 MX 首页使用内嵌 PNG，MX HTML 约 325 KB，旧识别规则及 256 KiB HTML 上限均会漏掉。新逻辑在生产容器独立只读进程验证：LLMPort 97,157 字节、Tosky 32,312 字节、MX 111,990 字节、AllTokens 41,351 字节，四站均成功识别 PNG。未修改运行中容器源码或数据库。

## 实现与边界

- 模型列表支持 OpenAI、Anthropic、Gemini，后两者按同域游标分页；仅保存明确返回的白名单字段。上下文与输入上限分别记录，不猜价格、介绍或模型授权。
- 模型与分组每小时在独立任务同步，也可由后台手动同步。失败保留上次成功资料；配置变更清空目录，原子更新校验配置版本与缓存版本，旧在途结果不得覆盖新配置。
- 分组优先读取密钥 billing，404/405 时回退公开 New API pricing，公开请求不发送密钥。人工分组可以补录并覆盖同标识资料；选择分组只切换资料，健康统计仍来自已配置密钥。
- 图标抓取继续使用公开 HTTPS 与 DNS 固定，仅允许有界栅格图片；HTML 上限 1 MiB、图片上限 256 KiB，拒绝 SVG/HTML 图标。成功结果持久保存在 `icon_cache`，不进入公开或后台 JSON；重启和源站失败时复用成功图标，换网站后拒绝旧缓存。
- 前端检查 hydration 前已完成的图片，失败有界重试并保留首字占位。服务端提供统一首屏时间，挂载后再更新相对时间，避免客户端时钟差触发 hydration 重建。
- 已阅读 PriceAI 的中转站采集流程、采集与 Sub2API 导入脚本和实时价格面板，参考公开资料与密钥探活分离的做法。普通 API 密钥不冒充 Sub2API 登录 JWT，不获取账户余额或用户资料。
