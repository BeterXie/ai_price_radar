# v3.9.31

中转站的首字与总耗时来自要求只输出最终整数的糖果题，首字自然可能紧邻响应结束。原“对话延迟”和“首 Token P50”容易让人误以为是普通短问答的响应速度。

页面现在显示“糖果题总耗时”和“糖果题首字 P50”，并在列表和卡片上方说明：首字等待包含推理时间，最终只输出一个整数，P50 是近 24 小时样本的中位数。提示文字区分了最新请求总耗时与首字统计窗口。计时仍从请求发起到第一个非空答案文本，不以心跳或思考片段作为首字。

2026-10-27 生产环境独立诊断：LLMPort 糖果题首字 18,652 ms、响应结束 18,735 ms，Tosky 为 23,137 ms / 23,366 ms，均只有一个答案文本事件。连续输出 1～50 的对照请求中，LLMPort 为 9,324 ms / 11,740 ms，Tosky 为 6,472 ms / 6,812 ms，均捕获 50 个文本事件。采集端能够记录早于响应结束的首字；这些独立诊断未写入监测统计。

不改变测试提示词、请求次数或统计数据，无数据库迁移。按 `docs/QUICK_DEPLOY.md` 的普通 API/Web 发布流程执行。
