# 分享与渠道归因

对比页和技能 / 文章页提供“复制分享链接”。链接使用公开站点地址和当前页面路径，移除原链接中的查询参数及锚点，再添加固定的读者分享标记：

```text
utm_source=pricememo&utm_medium=share&utm_campaign=reader_share
```

分享按钮只复制链接；剪贴板不可用时显示可手动复制的输入框。复制不会发送额外 PV，也不会自动对外发消息。

## 发布链接

每个发布渠道、素材使用独立的公开标记。例如：

```text
https://ai.pricememo.cn/compare?utm_source=qq&utm_medium=community&utm_campaign=launch_202611&utm_content=compare_01
```

只给外部发布链接添加这些标记；站内导航继续使用普通链接。`utm_source` 表示渠道，`utm_medium` 表示来源类型，`utm_campaign` 表示活动，`utm_content` 表示素材。标记应以小写字母开头，总长不超过 40 字符，只含小写字母、数字、点、下划线或连字符。点用于保留 `chatgpt.com` 一类平台标记。不要把用户标识、联系信息、密钥或自由文本写入任何标记。

`buildAnalyticsPath` 将这四个参数保留在主动上报的页面路径中；重复参数、格式不合要求的值和 `utm_term` 会被丢弃。原有搜索内容过滤、私有页面排除和分析偏好保持生效。单独添加、移除或变更活动标记，不会增加当前页面的 PV。

## 验证与读数

发布后做一次已标记链接的真实浏览验证，等待报表处理，再在百度统计的受访页面中核对参数，在来源报告中检查实际归类。SDK 接收路径并不保证百度按预期渠道分类；归类未核对前，不声称渠道归因已完整修复。GA4 若已启用并获得允许，其 `page_location` 同样包含经过过滤的活动参数。

基线和验收统一使用北京时间自然日；保留原始报表日期、筛选条件以及采集时间。当天未结束的数据单列。不要把窗口 UV 简单除以天数当作日均 UV，不要把统计接入前的无记录日期当作零流量；不同报表的实时刷新和指标口径可能存在差异。

私有增长报表、账号清单和待发布内容存放在被 Git 忽略的 `.runtime/growth/` 中。仅凭“直接访问”不能判断用户主动输入了网址，也不能证明流量来自搜索或 AI。
