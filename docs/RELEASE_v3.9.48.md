# v3.9.48

品牌报价原先只有 noindex 的查询参数入口，搜索引擎无法将其作为独立的 OpenAI、Claude 或 Gemini 比价页。现在 8 个品牌有固定的 `/brands/{slug}` 页面，旧链接永久跳转并保留搜索、库存和来源筛选；只有有报价且未筛选的品牌页允许收录。

首页、导航和 sitemap 连接到这些入口，品牌与商品页显示明确的比价标题及产品说明，全站标题后缀缩短为 PriceMemo。新增 `/compare`，展示实际收录的 ChatGPT、Claude、Gemini 套餐价格、库存、来源和更新时间，并连接官方说明及已有模型评测。报价不作为官方月费或模型能力排名。

本次包含搜索排名基线 `docs/SEO_AUDIT_2026-11-01.md`。搜索结果中的名次是当次浏览器观测；上线与索引通知不代表已收录或排名提高。

## 验证与部署

- 检查品牌规范地址、旧地址 308 跳转、筛选页 noindex、查询参数保留、品牌范围固定以及 sitemap。
- 运行 Web 测试、类型检查、生产构建和 API 发布门禁；CI 必须通过后才发布 Tag 并部署。
- 无数据库迁移，不涉及爬虫或数据管道。按 `docs/QUICK_DEPLOY.md` 备份、预检，重建 API、Web、importer 后切换 API 和 Web。
