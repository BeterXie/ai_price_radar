# v3.9.23 来源分组与中转站目录统一

申请收录只显示链动小铺、16688、独立站点和 API 中转站。独立站点提交后由隔离检测器确认实际建站系统，沿用现有审核设置；数据库和发布器仍保留实际来源类型。

报价目录和店铺目录的来源筛选统一把 Dujiao-Next、异次元/ACG-Faka、WooCommerce、Schema.org、商家 Feed 及其他独立站归入独立站点。该筛选同时作用于报价、商品详情和历史价格。

恢复 Dujiao-Next 的公开展示、已审核来源发布和快照导出。网络故障按来源隔离，保留报价时不修改观察时间；证书与数据格式错误仍使发布回滚。申请和发现流程继续遵循现有审批配置，不直接批准未审核来源。

生产只读核对发现 3 个已停用 Dujiao 来源仍在旧 SQLite 审批库中。发布时以当前收录状态为准，排除停用、拒绝及待审记录，避免旧库审批重新启用这些来源。

报价目录的中转站 tab 与 `/relays` 共用 `RelayCatalogPage`，读取同一份中转站与真实健康数据，并共享紧凑列表、卡片、刷新和申请交互。顶部中转站入口保留；店铺中转商品仍可通过交付方式筛选查看。
