# Changelog

## 2.0.0

- 默认扫描引擎改为 Playwright Chromium 持久会话。
- 删除随机伪造 `visitorid` 的请求方式。
- 支持人工正常完成验证并复用浏览器会话。
- 增加 403/验证/429 连续熔断。
- 失败扫描不再删除上次成功商品。
- 增加 v1 SQLite 自动迁移。
- 增加商品历史快照和扫描运行记录。
- 增加来源评分和候选优先级。
- 默认关闭 Wayback，提供单独历史扫描脚本。
- 重写分页停止逻辑。
- 增加 DOM 商品链接回退提取。
- 增加 Excel/CSV 公式注入和危险超链接防护。
- 增加运行摘要与运行历史工作表。
- 增加离线自检程序。
